Guide

처음 설정 순서

  1. 구글 스프레드시트를 만들고 Apps Script 코드를 붙입니다.
  2. Apps Script를 웹앱으로 배포합니다.
  3. 배포 URL을 이 파일의 config.js에 붙여넣습니다.
  4. GitHub Pages에 업로드합니다.
  5. 스프레드시트의 Programs 시트에 일정을 입력하면 앱 달력에 표시됩니다.

자세한 순서는 README.md 파일을 확인하세요.
